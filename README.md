# Project Workflow Tracker / 项目流程追踪器

**版本：v1.1.1**

一个轻量级的项目流程管理工具，支持事项依赖、多主题切换、甘特图视图和自定义模板。纯前端实现，无需后端服务。

## ⚠️ 用户数据存储说明

> 所有数据仅保存在当前浏览器的本地存储（LocalStorage）中。
>
> 必须使用同一浏览器、同一用户配置文件，且未清除浏览器缓存，数据才能保留。
>
> 建议用户及时导出备份，防止数据丢失。

## ✨ 功能特性

- **项目管理** — 新建、删除、切换多个项目，每个项目独立维护事项列表
- **事项与依赖** — 添加事项并设置前置依赖，未完成依赖时事项自动锁定（灰色），依赖完成后自动解锁（彩色）；支持随时编辑任意事项的依赖关系，内置循环依赖校验
- **完成时间追踪** — 自动记录每个事项的完成时间，显示"最后更新"时间戳
- **甘特图视图** — 基于实际完成时间戳绘制时间轴，已完成事项显示时间条，未完成事项显示状态标记（🔒/○），支持横向滚动
- **自定义模板** — 将项目事项保存为可复用模板，在新项目中快速应用
- **内置示例模板** — 首次加载即自带一套示例模板，可直接应用于新项目
- **6 种主题** — 浅色 / 蓝色 / 绿色 / 粉色 / 黄色 / 暗色，一键切换
- **停滞标记** — 为项目标注停滞原因，侧边栏红色边框高亮提醒
- **数据持久化** — 所有数据通过 `localStorage` 保存在浏览器中
- **数据导出与导入** — 支持将全部数据导出为 JSON 备份文件，并可从备份文件恢复数据
- **侧边栏宽度可调** — 拖拽侧边栏右边缘可自由调整宽度（200px ~ 500px），调整后自动记忆
- **个人水印** — 页面背景包含 "M4RCH" 水印文字

## 🚀 使用方法

### 本地打开

直接在浏览器中打开 `index.html` 即可使用：

```bash
# macOS
open index.html

# Windows
start index.html

# Linux
xdg-open index.html
```

### 通过静态服务器

```bash
# Python
python -m http.server 8080

# Node.js (npx)
npx serve .
```

然后访问 `http://localhost:8080`。

### 使用说明

1. 首次加载会自动创建"示例项目 — 项目流程"，并内置一套示例模板
2. 点击左侧项目卡片切换项目
3. 点击 **＋ 添加事项** 新建事项并设置依赖关系
4. 点击事项卡片右上角 **✎** 可随时编辑该事项的依赖关系
5. 点击 **💾 保存为模板** 将当前项目结构保存为自定义模板
6. 点击 **📑 使用模板** 将内置模板或自定义模板应用到当前项目
7. 点击 **📊 甘特图** 查看时间轴视图
8. 点击 **🎨** 切换主题配色

## 🛠 技术栈

- **Vanilla JavaScript** — 无框架依赖，零构建
- **localStorage** — 浏览器端数据持久化

## ⚠️ 关于本地数据

本应用的所有数据（项目、事项、模板、主题设置等）均保存在浏览器的 `localStorage` 中，**不会上传至任何服务器**。请注意以下几点：

1. **必须使用同一浏览器** — 数据与浏览器绑定，切换浏览器后数据不会同步
2. **必须使用同一用户配置文件** — 同一浏览器的不同用户配置文件之间数据互不相通
3. **清除浏览器缓存将导致数据丢失** — 请勿手动清除浏览器缓存或 localStorage 数据
4. **请及时备份数据** — 使用页面底部的「📤 导出数据」按钮将数据保存为 JSON 备份文件
5. **数据恢复** — 使用「📥 导入数据」按钮从备份文件恢复数据，导入时将覆盖当前所有数据
